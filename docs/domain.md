# 林地争议调解卷领域约定

项目面向集体林权改革与林下产业协作场景，由司法所与林业站共同建设调解卷。
卷宗采用只追加（append-only）事件日志作为唯一事实来源，业务记录区分来源、
发生时间与当前有效版本，所有对外结果都能追溯到采用的数据版本。

## 分层结构

1. **主体层**：当事人/单位与第三人，含未成年人、家庭隐私标记；代理人授权
   变更逐次留痕，旧授权终止时间自动记录，旧陈述永久归属于作出时的代理人。
2. **争点层**：边界、租金、历史口头约定等争点分别登记，可单独达成、撤回
   共识；共识按争点内独立编号（v1、v2……），撤回后历史保留、可再达成新版本。
3. **证据摘要层**：证据按到达顺序入卷，晚于举证期限的标记为迟到证据；
   每次达成共识时快照当时已到达的证据序号，迟到证据不重写既有共识。
4. **调解方案层**：封存调解书时逐争点锁定引用的共识版本；封存后该争点
   共识不可撤回或更改；签收状态一次确定、不可覆盖；履行按
   未履行/部分履行/已履行追加记录。
5. **签收与移交**：争议双方均签收且条款履行完毕才算和解；转入诉讼时
   锁定整卷版本号并冻结一切写入，未进入调解书的争点随卷移交；
   已部分和解的争点留在卷内按调解书继续履行。

调解会话允许时间重叠（并行调解），共识必须发生在进行中的会话内，
并由争议双方全体同意。

## 权限与脱敏

涉及个人、机构或敏感地点的信息只向职责范围内的角色开放。公开查询
（`Dossier.public_progress`）只返回脱敏进度：自然人以“当事人N”指代、
未成年人以“未成年人N”指代且不透露姓氏与家庭关系，不输出争点摘要、
证据摘要、陈述内容与方案条款。

## 结案复核

`Dossier.closing_review` 回放从受理、逐版本共识与撤回、封存签收、
部分履行到诉讼移交的完整时间线，回答“谁在何时同意了什么”以及
“未解决部分以哪个锁定版本如何移交”。
