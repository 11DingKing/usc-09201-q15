# 林地争议调解卷

本项目提供集体林权改革与林下产业协作领域的服务入口。代码库当前包含可运行的 HTTP 基础服务、健康检查和领域约定，业务数据与敏感配置应存放在受控环境中。

核心领域模型位于 `service/dossier.py`，以只追加事件日志实现调解卷五层结构（主体、争点、证据摘要、调解方案、签收/移交），支持逐争点共识与撤回、迟到证据快照、代理人变更留痕、并行调解会话、方案部分履行、转入诉讼版本锁定，以及只返回脱敏进度的公开查询；结案可通过 `closing_review()` 回放全过程。

运行 `python3 -m unittest` 可检查基础行为，执行 `python3 -m service.main` 后访问 `/health` 可确认服务状态。
